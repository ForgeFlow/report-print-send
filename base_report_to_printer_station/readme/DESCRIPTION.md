Send reports to the printer of the computer they are printed from, whoever is logged in.

A print station links one printer to the computers registered for it. A supervisor
registers a computer once from the station form: Odoo stores a random token in a cookie
of that browser and keeps only its hash. When a report uses the action "Use the
computer's print station", Odoo reads the cookie and sends the report to the station's
printer. A computer that is not registered cannot print: the user gets an error and
nothing is sent to any other printer.

The station of the current computer is shown in the top bar.
